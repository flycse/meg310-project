## Project Objective

Flycse aims to provide a user-friendly platform for real-time transportation data, enhancing how users interact with public transportation. This platform will include features like:
- **Bus schedules and routes** — Real-time updates and estimated arrival times.
- **API integration** — To fetch real-time data about bus locations, schedules, and updates.
- **User interface** — Designed for both web and mobile access.

## Technologies Used

- **Backend:** Node.js, Express
- **Frontend:** React.js, HTML5, CSS3
- **Database:** PostgreSQL
- **Mobile Application:** React Native
- **APIs:** IETT, IBB

## Setup and Installation

To run this project locally, follow these steps:

1. **Clone the repository:**
    ```bash
    git clone https://github.com/flycse/meg310-project.git
    ```

2. **Navigate into the project directory:**
    ```bash
    cd meg310-project
    ```

3. **Install dependencies:**
    ```bash
    npm install
    ```

4. **Start the development server:**
    ```bash
    npm start
    ```

5. **For mobile app (React Native):**
    Follow the [React Native setup instructions](https://reactnative.dev/docs/environment-setup) for your platform and run:
    ```bash
    npx react-native run-android
    ```
